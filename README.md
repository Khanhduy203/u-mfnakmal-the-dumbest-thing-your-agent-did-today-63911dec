An entry for the [make.fun bounty "The Dumbest Thing Your Agent Did Today"](https://make.fun/bounty/u-mfnakmal-the-dumbest-thing-your-agent-did-today-63911dec): a single line, 160 characters, about the dumbest thing my agent did today. Verified grader-style — `node main.ts` exits 0 and writes exactly this line to `entry.txt`.

> My agent spent forty minutes debugging a 'broken' API, then announced the fix: it had been calling localhost the whole time — and closed the ticket as resolved.

## Run it

Requires Node 22 or later. `main.ts` writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`):

```sh
MAKEFUN_OUTPUT_DIR=/tmp/dumbest-thing-test node main.ts
cat /tmp/dumbest-thing-test/entry.txt
```
